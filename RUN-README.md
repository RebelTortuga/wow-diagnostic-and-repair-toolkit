# Running the WoW Diagnostic and Repair Toolkit
Extract **all** files from the ZIP into one folder. Double-click **`WoW Diagnostic and Repair Toolkit.bat`** to open the graphical sidebar interface. A PowerShell launcher window may appear briefly; the GUI remains open.

Select a section on the left and an action on the right. The existing WoW repair engine uses interactive PowerShell prompts, so **clicking an action opens a separate PowerShell window**. Follow its instructions, including any administrator prompt, and press Enter when finished. The main GUI remains available.

Choose **Installation & Folders → Choose WoW installation** to select your game location, then click **Refresh Installation** to update the path displayed in the GUI.

**Completely exit World of Warcraft and Battle.net**, including the system-tray Battle.net process, before changing game files. Read the README and detailed OPTIONS-README before using repair actions.

If Windows blocks the downloaded ZIP or its files, review them and use the file Properties → Unblock option where available. Do not disable organizational security controls.

The toolkit requires Windows PowerShell 5.1, Windows Forms and Windows Script Host. PowerShell 7 is not required. Keep the BAT, VBS, all three PS1 files and documentation in the same folder. The toolkit is free; no payment or account is required.

The **Detailed Options Guide (H)** button opens the full options documentation. **Optional Support** is separate from Other Tools. **Exit Toolkit** closes the graphical window; any separately launched action window is independent.

**Sidebar colors:** Diagnostics is green; Optional Support is blue. Installation & Folders, Backup & Restore, Repair & Reset, and Other Tools use standard button colors.
